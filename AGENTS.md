# Project instructions

Before every build, implementation task, or code change, read
[ai-rules.txt](ai-rules.txt) and [min-requirement.txt](min-requirement.txt)
in full, including the mistake log. Reread them after a user correction,
an update to either file, or a loss of conversation context.

Follow the latest user-authorized scope. Recording a planned feature does
not authorize implementing it. Preserve unrelated website code and design.

When a verified AI mistake occurs, record its correction and a concrete
prevention step in ai-rules.txt, then apply that step to related work.
